\chapter{Annexes}

\section{Schémas techniques complémentaires}

Cette annexe regroupe les éléments techniques complémentaires utilisés pour appuyer la compréhension de la solution. Les principaux schémas d’architecture, de pipeline, de base de données et d’organisation applicative ont été intégrés directement dans les chapitres afin de faciliter la lecture du rapport.

Les annexes peuvent toutefois être enrichies par des schémas supplémentaires en cas de besoin, notamment pour détailler davantage l’organisation interne du pipeline, les relations entre les tables MySQL ou les flux d’échange entre le backend et les interfaces applicatives.

\section{Captures d’écran complémentaires}

Les captures les plus importantes ont été intégrées dans les chapitres de développement et de résultats. Elles concernent principalement l’orchestration Prefect, la base MySQL, les tests backend, les dashboards Power BI, l’application mobile et le portail back-office.

Cette annexe peut être utilisée pour ajouter des captures complémentaires qui ne sont pas indispensables dans le corps du rapport, mais qui permettent de documenter davantage l’environnement de travail, les tests ou certaines vues applicatives.

\section{Exemples techniques anonymisés}

Les exemples techniques présentés dans le rapport ont été sélectionnés afin de préserver la lisibilité et la confidentialité des données. Les extraits liés aux configurations, aux endpoints, aux résultats de validation et aux structures de tables sont utilisés à titre illustratif.

Les informations sensibles, notamment les identifiants, mots de passe, adresses internes ou données nominatives non nécessaires à la compréhension du projet, ne sont pas affichées dans le rapport.
