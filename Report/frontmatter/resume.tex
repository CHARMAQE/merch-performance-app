\textbf{Résumé --- Français}

Ce projet porte sur la mise en place d'une plateforme data-driven pour le suivi de l'exécution terrain du merchandising Unilever chez Smollan Morocco. La solution centralise les données Data Dump et Coverage, automatise leur traitement via un pipeline ETL Python, les stocke dans MySQL et propose des interfaces de suivi, d'analyse et de validation opérationnelle.

\textbf{Mots-clés :} Data Engineering, ETL, MySQL, merchandising, validation métier, OSA, back-office.

\vspace{0.5cm}

\textbf{Abstract --- English}

This project focuses on building a data-driven platform for monitoring Unilever merchandising field execution at Smollan Morocco. The solution centralizes Data Dump and Coverage data, automates processing through a Python ETL pipeline, stores it in MySQL, and provides monitoring, analysis, and operational validation interfaces.

\textbf{Keywords:} Data Engineering, ETL, MySQL, merchandising, business validation, OSA, back-office.
